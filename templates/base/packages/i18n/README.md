# @repo/i18n

Shared i18next resources and helpers. UI copy uses translation keys only.

## Includes

- `en` catalog for `auth.*` and `errors.*` (aligned with `@repo/contracts` `ERROR_KEYS`)
- `createI18n()` for app bootstrap
- `translateApiError` / `translateErrorKey`

Wizard later clones extra locale stubs from this package.
